# Prever o retorno de Investimentos com Temporal Fusion Transformers

Este projeto aborda diversas atividades: 

- criação de indicadores financeiros para análise de dados
- engenharia de atributos em dados de série temporal multivariada, 
- construção do modelo Temporal Fusion Transformer 
- criação da estratégia para previsão do retorno de aplicações financeiras.

Os dados usados são reais, disponíveis publicamente e coletados em tempo real

### Instruções:

Abra o terminal ou prompt de comando, navegue até a pasta com os arquivos e execute o comando abaixo para criar um ambiente virtual:

```bash
conda create --name venv5 python=3.12
```

Ative o ambiente:

```bash
conda activate venv5 (ou: source activate venv5)
```

Instale o pip e as dependências:

```bash
conda install pip
pip install -r requirements.txt 
```

Execute o jupyter:

```bash
jupyter notebook
```

Acesse pelo navegador padrão.

Use os comandos abaixo para desativar o ambiente virtual e remover o ambiente (opcional):

```bash
conda deactivate
conda remove --name venv5 --all
```
