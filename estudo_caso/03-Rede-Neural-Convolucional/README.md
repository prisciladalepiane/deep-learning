# Deep Learning com Rede Neural Convolucional em C++

1 - Ter o CMake instalado na sua máquina

2 - Abrir o terminal ou prompt de comando e navegue até a pasta onde estão os arquivos do projeto.

3 - Criar e acessar a pasta build:

```cmd
mkdir build
cd build
```

4 - Executar o comando abaixo para validar a compilação:

```cmd
cmake ..
```

5 - Executar a compilação:

```cmd
make
```

6 - Acessar a pasta build e executar os comandos abaixo:

```cmd
./testeunitario
```

```cmd
./treino ../dados/train-images-idx3-ubyte ../dados/train-labels-idx1-ubyte ../dados/t10k-images-idx3-ubyte ../dados/t10k-labels-idx1-ubyte
```
